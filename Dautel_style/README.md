# Dautel_style

Everything needed to apply the Dautel brand to a project. Start with `BRAND.md`.

| Path | What |
| --- | --- |
| `BRAND.md` | Brand rules: identity, voice, color, type, shape, motion, icons, components |
| `dautel.css` | The stylesheet: all five themes (Catppuccin Mocha default), fonts, base styles, components |
| `index.html` | Example page using the stylesheet, logo and favicon (open it in a browser) |
| `logos/` | Canonical logo, mark and favicon SVGs |
| `fonts/install/JetBrainsMono-NerdFont/` | JetBrainsMono Nerd Font, 16 styles, to install on your computer |
| `fonts/web/` | Manrope and JetBrains Mono web fonts plus `fonts.css`, for projects that must work offline |

Install the Nerd Font once: select all the `.ttf` files, then right-click → Install (Windows) or double-click → Install Font (Mac).

The online source of this system is https://claude.ai/artifact/TbPoRVLANSdVx3SujjkpTC. These files are a copy and don't update by themselves.
